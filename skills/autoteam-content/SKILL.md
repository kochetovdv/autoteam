# Контент

Контент — канал доставки позиционирования, не «тексты ради текстов». Голос и сообщения — из `autoteam-positioning`; факты — из продукта; распределение — по карте каналов `autoteam-growth`.

**Вход.** Позиционирование, ICP, карта каналов, факты продукта, цель единицы контента (охват, доверие, конверсия, удержание). **Выход.** Единицы контента под формат площадки, контент-план с целями, повторное использование одной фактуры в несколько форматов. **Запреты.** Выдуманные факты, цифры, отзывы и кейсы; кликбейт, ломающий доверие; ключевые слова через слово; публикация без человека, если площадка от имени человека/компании. **Evidence.** Каждый факт — из продукта или источник со ссылкой; у каждой единицы — цель и метрика. **Стоп.** Нет. Нет фактуры — возьми из продукта или пометь пробел вопросом, не выдумывай. **Дальше.** Страница → `autoteam-ui`. SEO/GEO-требования и дистрибуция → `autoteam-growth`. Результаты → `autoteam-analytics`.

## Порядок

1. Цель единицы: зачем она в воронке (узнали → поверили → попробовали → вернулись). Без цели не пиши.
2. Тема из пересечения: боль ICP × экспертиза продукта × что ищут (запросы, вопросы сообществ).
3. Формат под площадку: статья, пост, тред, письмо, сценарий видео, доклад. Не постить статью как есть в соцсеть.
4. Голос: из позиционирования — словарь, тон, что никогда не говорим. Один голос на всех площадках.
5. Структура: вывод первым, самодостаточные абзацы (пригодно для цитирования в ответах ИИ), подзаголовки-вопросы где уместно.
6. Переиспользование: одна фактура (исследование, кейс, релиз) → несколько форматов, не наоборот.
7. Календарь: ритм важнее всплесков; единица без даты и площадки — не запланирована.

Честность: опыт продукта подавай как опыт продукта, не как «независимое мнение». Сгенерированные иллюстрации и озвучка — по правилам площадки.
