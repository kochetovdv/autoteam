# skills/ — канон

Каждая папка `autoteam-<имя>/` содержит `SKILL.md` и при нужде `reference.md`. Набор самодостаточен: скилл работает и без остального репозитория (ссылки на `docs/` и `templates/` — углубление, не зависимость).

Использование как библиотеки: скопируй папки в каталог скиллов своей агентной среды (Claude, Cursor, свой раннер) целиком, без правок. Канон правится только здесь; после правки разнеси копии заново. Проектные особенности — в overlay продукта, не в каноне.
