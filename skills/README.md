# skills/ — canon

Each `autoteam-<name>/` folder contains `SKILL.md` and, when needed, `reference.md`. The set is self-sufficient: a skill works without the rest of the repository (links to `docs/` and `templates/` are depth, not dependency).

Using it as a library: copy the folders into your agent environment's skills directory (Claude, Cursor, your own runner) whole, without edits. The canon is edited only here; after an edit, re-distribute the copies. Project specifics go in the product overlay, not in the canon.
