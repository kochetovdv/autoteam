# Журнал решений (автономный режим)

Каждое решение, которое в интерактивном режиме ушло бы человеку, фиксируется строкой. Человек читает журнал после, а не согласовывает до.

| ID | Дата | Решение | Почему так | Альтернатива | Обратимость | Кто принял |
|----|------|---------|------------|--------------|-------------|-----------|
| D-001 | | | | | легко / дорого / необратимо | роль агента |

Правила:

- Необратимое и внешние деньги в журнал не попадают — это жёсткий стоп, не решение агента.
- «Обратимость: дорого» — решение помечается для приоритетного чтения человеком.
- ASSUMP из spec/scope сюда не дублируются — здесь выборы («взяли X, а не Y»). Исключение: ASSUMP, меняющие рынок, аудиторию или деньги, дублируются сюда обязательно.
- Журнал append-only: поздний артефакт уточнил или отменил решение — к записи добавляется амендмент со ссылкой («D-004a: уточнено в spec §5»), запись не переписывается. Проверка «журнал не противоречит финальным артефактам» — пункт приёмки.
- Амендмент, меняющий ASSUMP или решение, перечисляет зависимые артефакты и порождает задачу их ревизии.
