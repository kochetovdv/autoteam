# Assignment starter

Use only fields that help; infer known settings from the project profile. This is an optional starting message, not a questionnaire.

```text
Outcome and beneficiary: <what should be achieved, for whom, and why>
Known facts and sources: <links/materials already available>
Scope and constraints: <important boundaries>
Working/output location: <if not already known>
Mode: solution | interactive | inherit profile
Task limit: none specified | <money/tokens/calls/elapsed time>
Production authority: closed | <explicitly authorized scope>
```

The agent supplies the brief, selects and launches roles, proposes useful monitoring where justified, and maintains evidence, knowledge, and owned resources. Apply the full method from a pinned verified bundle; do not silently update shared/global skills. Review/analysis output goes to the allowed location without modifying its subject. An explicit continuation names the interrupted cycle; otherwise a new assignment starts a new state after relevant knowledge is rechecked.
