# Go: ремесло

Читай этот файл, **если сервер продукта на Go**. Не назначай Go, если в репозитории другой стек (`docs/process/stack.md`). Цель — читаемый модульный монолит, явные ошибки, безопасный параллелизм.

## Пакеты

- Один бинарник API (и отдельно worker, если фон реально другой процесс). Не дроби на микросервисы без ADR.
- Границы: `internal/<модуль>/` — публичные типы модуля маленькие. Соседний модуль не ходит в чужую таблицу напрямую.
- `cmd/api`, `cmd/worker` — только сборка и флаги.
- Доменные правила не импортируют HTTP-фреймворк. HTTP — адаптер.
- Гексагон: порты (интерфейсы) в модуле, реализации в `internal/infra/`. Вводи, когда появился второй вход (очередь, CLI, легаси), не «для чистоты».

## Ошибки и контекст

- Ошибки оборачивай с контекстом (`fmt.Errorf("…: %w", err)`). На границе HTTP — код и безопасное тело, не стек клиенту.
- `context.Context` первым аргументом в I/O. Отмена и дедлайн обязательны на исходящих вызовах.
- Не храни Context в структуре на всю жизнь запроса, кроме явно документированного случая.

## Гонки

- Общий курсор, статус, «владелец джобы», баланс — не read-modify-write без защиты.
- Средства: транзакция с понятным уровнем изоляции, `SELECT … FOR UPDATE` там, где это уместно, сравнение-и-установка, очередь с одним потребителем ключа, `mutex` только на память процесса (не вместо БД).
- Тест: два параллельных клиента на один ключ. Нет теста — нет закрытия для L3.

## Идемпотентность

Повтор POST с тем же ключом не создаёт вторую сущность. Ключ — заголовок или поле, хранится с результатом.

## Миграции

- SQL-файлы с номерами, только вперёд плюс описанный откат или expand/contract.
- Не править уже применённую миграцию на проде. Новая — новый номер.
- Совместимость со старым кодом на время выкатки (сначала добавить колонку, потом читать).

## Тесты

- Unit: правила без сети.
- Integration: реальная БД в docker или testcontainer, не мок всего драйвера.
- Гонка и идемпотентность — отдельные тесты, не «покрыто хендлером».

## Наблюдаемость в коде

Лог: `request_id`, сущность (id), ошибка. Не ПДн и не секреты. Метрика: латентность входа, ошибки 5xx, длина очереди. Трассировка — если больше одного процесса на запрос.
