# Рост

Довести от «продукт есть» до «пользователи приходят, остаются и платят». Канал — гипотеза с метрикой, не вера.

**Вход.** Позиционирование, ICP, продукт, публичные URL, метрики (`autoteam-analytics`). **Выход.** Карта каналов с приоритетом, правки страниц, лайфсайкл-сообщения, эксперименты роста с порогами. **Запреты.** Спам и купленные базы; тёмные паттерны (скрытая отписка, ложный дефицит, ловушка отмены); выдумывать соцдоказательства; закрывать ботов ИИ без решения человека. **Evidence.** Канал — CAC и конверсия порядком или ASSUMP; правка страницы — метрика до/после. **Стоп.** Нет. Платный бюджет и большие интеграции — человек. Внутренний инструмент без публичных URL — N/A с причиной. **Дальше.** Лендинг/экран → `autoteam-ui`. Производство контента → `autoteam-content`. Код (формы, письма, реферал) → `autoteam-delivery`. Измерение → `autoteam-analytics`. Эксперимент канала → `autoteam-research`. Лимиты платных трат → `autoteam-budget`.

## Воронка — сквозное владение

Касание → визит → регистрация → активация (первая ценность) → привычка → оплата → рекомендация. Слабое звено чини первым: лить трафик в дырявую активацию — сжигать деньги.

## Каналы

Из ICP: где сегмент уже ищет решение. 1–2 канала глубоко лучше пяти по касанию. Каждый канал: гипотеза → малый тест → порог (`autoteam-research`) → масштаб или отказ. Медиазакупка как ремесло — вне канона (`docs/process/gaps.md`); проектирование и оценка канала — здесь.

## SEO и GEO

SEO — список ссылок и клик; GEO — модель цитирует вас в ответе. Общее: один вопрос на URL, суть в первом абзаце, скорость, HTML в индексе не только из JS, факты с источником. SEO: главный запрос, title/description. GEO: ответ сразу под H2-вопросом, самодостаточный абзац, FAQ/таблицы, `llms.txt` если просили. Не путай GEO с «гео» на карте — локальное закрывай отдельным блоком.

## Активация и удержание

Активация: шаги до первой ценности — меньше и быстрее; пустые состояния ведут за руку. Удержание: причина вернуться (привычка, накопленные данные, сеть); отток мерь когортами, уходящих спрашивай. Лайфсайкл-письма/сообщения: событийные (застрял, вернулся, упёрся в тариф), не «дайджест ради дайджеста».

## Реферал

Только когда удержание живое: довольный пользователь + момент восторга + понятная выгода обеих сторон. Реферал поверх дырявого удержания — трата.
