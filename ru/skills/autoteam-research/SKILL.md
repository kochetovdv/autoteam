# Исследование

Уменьши неизвестность. Демо без метода — не evidence. Код эксперимента не в прод этим запуском.

**Вход.** Неизвестность, которую надо сузить. **Выход.** Протокол, сырые логи, вердикт `ADOPT` | `REJECT` | `CONTINUE_RESEARCH`, дыры до производства. **Запреты.** Двигать порог после цифр без нового эксперимента; сливать эксперимент в прод. **Evidence.** Baseline, порог, timebox, версии среды. **Стоп.** Нет. Независимые задачи не стопай. Выбор стека по результату — человек, если это смена платформы. **Дальше.** ADOPT в продукт → `autoteam-architecture` + `autoteam-delivery`.

Протокол: какое решение откроет результат → опровержимая гипотеза → данные похожие на боевые, baseline, порог, timebox → версии среды → сырые логи → ограничения → вердикт → дыры до производства.
