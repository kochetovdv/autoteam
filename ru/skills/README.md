# Навыки и полный комплект

Каждый `autoteam-*/SKILL.md` определяет назначение, основные ограничения и маршрут ответственности. Дополнительные документы читаются по необходимости. Отдельный навык даёт локальное руководство; если он требует общие документы, это зависимости, а не необязательный фон. Недоступные зависимости не позволяют заявлять соблюдение полного метода.

Полный метод — один версионированный комплект: `canon.json`, корневые входные документы, `skills/`, `docs/`, `templates/`, поддерживаемые соответствия `ru/` и скрипт проверки. На цикл сохраняется проверенный неизменяемый снимок. Где возможно, регистрируй навыки из него. Если среде нужны копии для обнаружения, привяжи их к тому же снимку и разрешай общие ссылки там; копирование только папок навыков не является полной установкой.

Профиль проекта фиксирует корень канона, версию/отпечаток, язык и места регистрации в среде. Не обновляй попутно глобальные навыки пользователя, общую рабочую копию канона или инструкции активного цикла. `scripts/check_canon.py --compare <bundle-root>` сверяет полный скопированный комплект с этим источником; он ничего не устанавливает и не доказывает поведение агентов.

Изменения метода делаются здесь; команды проекта, доменные значения, местные запреты, ID моделей и визуальные референсы остаются в профиле/overlay. `autoteam-retro` предлагает общий урок из доказательств проекта. Явное поручение изменить канон разрешает реализовать это предложение.
