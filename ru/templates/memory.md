# Проверенная память проекта

Долговечные факты и уроки, полезные за пределами активного цикла. Если хранилище знаний уже есть, используй его. Метод: `docs/process/project-knowledge.md` в проверенном снимке канона. Ниже незаполненный шаблон, а не установленные знания проекта.

```markdown
ID записи / ревизия / время записи (с часовым поясом):
Статус: proposed | verified | pending-recheck | superseded
Факт или урок:
Область / условия применимости:
Время наблюдения / на какую дату верен факт (с часовым поясом; unknown, если не установлено):
Наблюдение и вывод (если это урок):
Первоисточники → место / ревизия или отпечаток содержимого:
Проверка → метод / дата / результат / ограничения:
Принятое изменение / проверяющий / ссылка на приёмку:
Зависимые записи / артефакты:
Владелец / событийные триггеры / предельная дата перепроверки (либо обоснование проверки только по событию):
Заменяет / заменена записью:
```

- Авторы предлагают небольшие дельты; принимающий проверяет их вместе с принимаемым изменением. Только принятые записи с evidence получают `verified`.
- `verified` ограничен датами наблюдения и проверки. Перед текущим использованием сравни запись с относящимися к задаче актуальными фактами, зафиксируй применимость в зависимой единице работы/решении. Свежая дата записи или неизменный хеш источника не подтверждают актуальность.
- Догадка, допущение, сжатие чата и сводка другого агента — не факт из источника. Обращайся к первичному evidence; неразрешённые гипотезы остаются вне проверенной памяти.
- Изменение источника, противоречие или непригодное извлечение помечают зависимые записи `pending-recheck` до новой проверки. Сохраняй ревизии и ссылки замещения.
- Агент выводит настройки перепроверки из риска и действующих предпочтений. Для изменчивых или существенных для решения предпосылок нужны владелец, триггеры и предельная дата; стабильным фактам допустима обоснованная проверка только по событию. Давняя дата или наступивший срок не опровергают исторический факт. Неизвестная текущая применимость остаётся явной; проверяй нужные предпосылки, а не всю память целиком.
- Настройки — в профиле, желаемое поведение — в спецификации, выборы — в журнале, текущие задачи — в состоянии. Не дублируй их здесь.
- Никаких сырых секретов, логов, транскриптов инструментов и истории чата. Ссылайся лишь на необходимое очищенное evidence. Долговечное ограничение включает реальную проверку, область и триггер перепроверки; сбой инструмента не доказывает отсутствие в продукте.
