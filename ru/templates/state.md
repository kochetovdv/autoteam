# Состояние цикла

Текущая картина мира цикла, лежит в `docs/process/state.md` продукта. Здесь то, что нужно волне, чтобы продолжить; всё остальное живёт в журнале, артефактах и чекпойнтах.

Состояние — не история. Журнал решений — append-only история для ретро; состояние — изменяемое настоящее для исполнения. Нужны оба, одно другое не заменяет.

## Схема (поля метода — есть всегда)

| Поле | Что держит | Примечание |
|------|---------|-----------|
| `cycle` | id, поручение одной строкой, режим (интерактивный / решение), старт | из брифа |
| `phase` | где сейчас петля | product / positioning / scope / architecture / delivery / release / analytics |
| `packages` | пакет → статус → владелец | статусы: план, в работе, на ревью, `Blocked-by-resource`, готово |
| `decisions` | D-id действующих решений | ссылки, не текст — текст в журнале |
| `assumptions` | ASSUMP, на которых стоит текущая работа | с триггером пересмотра |
| `blockers` | что чем застопорено, владелец, дата | включая открытые сужения периметра |
| `resources` | ссылка на реестр ресурсов продукта | плюс что ждём от человека |
| `verdicts` | последние вердикты борда и число возвратов | вход приёмки |
| `awaiting_human` | только жёсткие стопы | всё остальное — решение |
| `costs` | время, токены/вызовы, если среда их отдаёт | вход ретро |

Продуктовые поля добавляет overlay продукта (фиксация стека, среда, свои сущности). Overlay расширяет схему, не переписывает поля метода.

## Правила

- **Волна — это шаг.** Субагент запускается от skill + состояние + поручение своей волны, никогда от транскрипта. Всё, что должно пережить волну, идёт в состояние: чего нет в состоянии — теряется по замыслу, а не по недосмотру.
- **Патч, не переписывание.** Волна возвращает дельту: какие поля изменились, что добавлено, что удалено явно. Дельта, молча теряющая существующие поля, невалидна и возвращается автору. Удаление всегда явное.
- **Автор не сливает свой патч сам.** Дельту применяет оркестратор (или приёмщик) — граница автор ≠ приёмщик распространяется на состояние. Невалидный патч — возврат, а не починка на ходу.
- **Свежее наблюдение бьёт состояние, состояние наблюдение — никогда.** Расхождение реальности с состоянием — стоп до правки состояния; работать поверх заведомо устаревшего состояния запрещено.
- **Шум не попадает внутрь.** Логи, телеметрия, вывод инструментов — наблюдения; в состояние коммитится только их следствие. Поле, которое никто не читает на следующей волне, в схеме не нужно.
- **Сводка чата — не состояние.** Сжимать историю ради влезания в контекст вместо ведения состояния запрещено: сводка теряет ровно те идентификаторы и зависимости, которые нужны следующей волне.
- **Один писатель на волну.** Параллельные ветки возвращают свои дельты; слияние — за оркестратором, в конце волны, по правилам общей изменяемой границы.
- **Состояние чекпойнтится вместе со всем остальным.** Восстановление цикла = состояние последнего чекпойнта плюс журнал.

## Шаблон

```
cycle: C-001 | «<поручение одной строкой>» | режим: решение | старт: ГГГГ-ММ-ДД
phase: delivery

packages:
  P-01 <название> — готово — <роль>
  P-02 <название> — в работе — <роль>
  P-03 <название> — Blocked-by-resource R-002 — <роль>

decisions: действуют D-001..D-007; D-004 амендмент D-009
assumptions:
  A-01 <допущение> — пересмотр при <триггер>

blockers:
  B-01 <что стоит> — <причина> — владелец — перепроверка ГГГГ-ММ-ДД

resources: docs/process/resources.md; ждём от человека: R-002 (учётка)
verdicts: борд ГГГГ-ММ-ДД — ACCEPTED, N неблокирующих, возвратов: N
awaiting_human: нет
costs: 3 волны, ~N ч; токены: <если среда отдаёт>
```
