# Архитектурное ревью

Это не code review одного PR. Смотри связи, данные, отказы, права.

Каденс и skill: `autoteam-architecture-review`. Шаблон отчёта: `templates/architecture-review.md`.

Активный продукт: раз в неделю или каждые ~8 задач. Спокойный: раз в месяц. Инцидент с данными, гонкой, отказами, блокировкой — вне очереди.

Пока ревью идёт, независимые задачи продолжаются. Стоп — только scope с Blocker (остановка сервиса, потеря данных, дыра в правах, гонка с порчей состояния, несовместимый контракт).

Измерения: границы; владелец данных; гонки и идемпотентность; роли на сервере; отказы и наблюдаемость; простота (KISS); долг с владельцем и датой.

Вердикт: `HEALTHY` | `WATCH` | `REMEDIATE`. REMEDIATE ≠ стоп всей разработки.
