# Стек продукта

Стек и состав клиентов принадлежат текущему продукту.

1. Начинай с имеющихся lockfile, ADR и явных решений проекта. Смена стека живого продукта требует соответствующих полномочий; не подменяй его молча.
2. Нет стека в **интерактивном режиме**: один существенный вопрос; останавливается только работа, зависимая от выбора.
3. Нет стека в **автономном режиме**: выбери минимальный достаточный стек для согласованного результата, включая нужный визуальный уровень и поведение, зафиксируй альтернативы и допущения, продолжай. Это же правило действует для UI и поставки; отсутствие стека не превращается в повторную анкету.
4. Новые клиентские платформы (web/адаптив/PWA/native) — явное решение по объёму с учётом цены. Не добавляй платформу молча.
5. Ремесло языка/фреймворка — в профиле/overlay проекта. Универсальные правила корректности и границ применяются на языке продукта.
